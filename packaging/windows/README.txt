MIK to Rekordbox (Windows)
==========================

Sync Mixed In Key playlists into Rekordbox (track order preserved).

Install
-------
1. Download MIK-to-Rekordbox-win64.zip from GitHub Releases.
2. Extract the zip to a folder (e.g. Desktop\MIK to Rekordbox).
3. Run MIK-to-Rekordbox.exe.

If SmartScreen warns you, click "More info" → "Run anyway" (first time only).

Before syncing (database method — recommended)
----------------------------------------------
• Mixed In Key 11 with your playlists
• Rekordbox 6/7 with the same music files in your library
• Fully quit Rekordbox before clicking Sync

In the app
----------
• Click Refresh to load MIK playlists
• Select one or more playlists
• Use "Database (recommended)" and enable filename matching if paths differ
• Click Sync selected

Synced playlists appear under "MIK Sync" in Rekordbox.

Default paths
-------------
• MIK database: %LOCALAPPDATA%\Mixedinkey\Collection11.mikdb
  (or under Mixed In Key — the app searches common locations)
• Rekordbox XML: %USERPROFILE%\Documents\rekordbox\rekordbox.xml
