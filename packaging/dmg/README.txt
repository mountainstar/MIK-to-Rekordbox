MIK to Rekordbox
================

Sync Mixed In Key playlists into Rekordbox (track order preserved).

Install (pick one)
------------------
Easy: double-click **Install.command** on this disk.

Or: drag **MIK to Rekordbox.app** onto the **Applications** folder shortcut.

Then open Applications and launch MIK to Rekordbox.
If macOS blocks the app: right-click → Open → Open (first time only).

Optional CLI: after installing, double-click **Add CLI command.command**
to add a `mik-sync` command in Terminal (symlink in /usr/local/bin).

Before syncing (database method — recommended)
----------------------------------------------
• Mixed In Key 11 with your playlists
• Rekordbox 6/7 with the same music files in your library
• Quit Rekordbox completely (Cmd+Q) before clicking Sync

In the app
----------
• Click Refresh to load MIK playlists
• Select one or more playlists
• Use "Database (recommended)" and enable filename matching if paths differ
• Click Sync selected

Synced playlists appear under "MIK Sync" in Rekordbox.

Requirements: macOS 12+, Apple Silicon or Intel Mac (build matches the DMG architecture).
